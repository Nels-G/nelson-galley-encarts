# Changelog

Toutes les évolutions notables du plugin. Format inspiré de [Keep a Changelog](https://keepachangelog.com/fr/1.1.0/), versions [SemVer](https://semver.org/lang/fr/).

## [1.0.0] — 2026-11-13

### Ajouté
- Type de contenu « Encart » avec 6 types : offre, formation, application, événement, partenaire, sponsorisé.
- Emplacements automatiques : milieu d'article, fin d'article, accueil ; code court `[encart id="…"]`.
- Ciblage par rubrique et période de diffusion.
- Statistiques d'affichages et de clics (hors administrateurs et robots).
- Lien `rel="sponsored nofollow"` et mention de l'annonceur pour les encarts commerciaux.
- Mises à jour depuis les releases GitHub (`Update URI`).
