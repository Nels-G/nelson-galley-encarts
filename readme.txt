Publicités maison : offres, formations, applications, événements, partenaires et espaces sponsorisés, avec statistiques.

== Description ==

Diffusez vos propres encarts sur votre blog : offres de service, formations, applications, événements, partenaires et espaces sponsorisés.

* 6 types d'encarts avec badge
* Emplacements automatiques : milieu d'article, fin d'article, accueil
* Code court [encart id="123"]
* Ciblage par rubrique et période de diffusion
* Statistiques d'affichages et de clics, sans cookie
* Lien rel="sponsored" et mention « Proposé par » pour les encarts commerciaux
* Mises à jour depuis les releases GitHub

== Installation ==

1. Extensions › Ajouter › Téléverser une extension, puis choisir nelson-galley-encarts.zip.
2. Activer l'extension.
3. Créer vos encarts dans le menu « Encarts ».
